# AgriMind AI — Web (Frontend)

Next.js 16 / React / TypeScript frontend for AgriMind AI. See the repository root `README.md` for full local setup instructions (backend, database, running both apps together).

## Quick reference (frontend only, assumes the API is already running)

```bash
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
npm run test        # Jest + React Testing Library
npm run lint         # ESLint
npx tsc --noEmit    # TypeScript check
npm run build        # production build
```
